name
FAQ Accordion
description

Dynamic, index-driven FAQ accordion. Instead of authoring each Q&A, the block reads a query-index built over the FAQ pages and renders one collapsible item per FAQ (page title = question, description = answer). The single source row makes the query-index path explicit (e.g. /us/en/faqs/query-index.json). Used on the FAQs page. Add or edit a FAQ page and the accordion updates automatically.
