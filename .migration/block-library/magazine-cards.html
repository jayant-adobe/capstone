name
Magazine Cards
description

Dynamic, index-driven grid of magazine article cards. Reads a query-index and renders one card per article (image, title, teaser) — no per-card authoring. Row 1 source = the query-index path (e.g. /us/en/magazine/query-index.json); optional limit caps the count for teasers, and order-field chooses the sort column (e.g. listOrder). Used on the homepage "Recent Articles" teaser and the Magazine listing "All Articles".
