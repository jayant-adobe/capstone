WKND Project Block Library

The set of Edge Delivery Services blocks required to build the WKND site. Each block below links to a live demo page authors can copy from, and the whole set is registered in library.json for use with the AEM Sidekick Block Library.

How to use

In the AEM Sidekick, open the Library and point it at /block-library/library.json on this site. Each entry loads the matching demo page, from which authors can copy a fully-structured block into their own document.

The header and footer are site-wide blocks configured once via nav and footer documents, so they are not part of the copyable block library.
