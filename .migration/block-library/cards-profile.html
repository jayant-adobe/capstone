Team/contributor profile card with a circular portrait, name, role and a row of social links. Author one block per person: cell 1 = portrait image, cell 2 = name (h3), role (h5) and one paragraph per social link. Use several in a section for an About Us people grid. For a data-driven grid that renders from a sheet, use Profile Cards.
