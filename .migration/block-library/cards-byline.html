name
Cards Byline
description

Compact single-author byline row for the end of a magazine/blog article — portrait, name, role and a row of social links, laid out horizontally. One row: cell 1 = portrait image, cell 2 = name (h2), role (h5) and one paragraph per social link. Use for author attribution; for team/contributor grids use Profile Cards instead.
