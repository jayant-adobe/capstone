name
Widget
description

Loads a self-contained mini-app (HTML + CSS + JS) from the project's /widgets/ folder. Author a link to /widgets/<name>.html (optionally in a folder, with query params for config) and it auto-blocks into a widget — the block name is derived from the file name. Use for interactive elements that need their own markup and script. Requires a matching widget under /widgets/ in the codebase.
