name
Adventure Cards
description

Dynamic, index-driven grid of adventure cards. Instead of authoring each card, the block reads a query-index and renders one card per adventure page (image, title, teaser). Row 1 source = the query-index path (e.g. /us/en/adventures/query-index.json); optional limit caps the count (used for the homepage teaser). Used on the homepage "Recent Adventures" teaser and the Adventures listing.
