name
Tabs Filter
description

Category filter bar that shows/hides cards in the next sibling cards block within the same section. Each row is one category label; "All" clears the filter. Unlike Tabs (one panel per tab), this renders only the filter chips and toggles matching cards — so authors keep a single flat cards grid instead of nesting cards inside tab panels. Used on the Adventures listing to filter by activity. Author the categories here and a matching Adventure Cards block directly below.
